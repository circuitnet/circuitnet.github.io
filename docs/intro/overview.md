<div><h1 id="dataset-overview" tabindex="-1"><a class="header-anchor" href="#dataset-overview"><span>Dataset Overview</span></a></h1><p>The dataset provides multi-modal features (image and graph) to support four cross-stage prediction tasks in back-end design: congestion prediction, DRC violations prediction, IR drop prediction, and net delay prediction. For the first three tasks, the common practice is to leverage computer vision methods (e.g., CNN or FCN), thus the main part of CircuitNet for these tasks is 2D image-like data. In addition, for congestion prediction and net delay prediction that can be completed on graph, we also provide graph features to support graph construction.</p><h2 id="image-like-feature-maps" tabindex="-1"><a class="header-anchor" href="#feature-categories"><span>Feature Categories</span></a></h3><ul><li><p><strong>Macro Region</strong>: The regions covered by macros, used for estimating routing resources available in each tile.</p></li><li><p><strong>Routability Features</strong>:</p><ol><li><strong>Cell density</strong>: The cell number counted in each tile.</li><li><strong>RUDY</strong>: A routing demand estimation for each net over spatial dimension. It is widely used for its high efficiency and accuracy. A variation named pin RUDY is also included as the pin density estimation.</li><li><strong>Pin configuration</strong>: A high resolution representation of pin and routing blockage shapes that conveys pin accessibility in routing.</li><li><strong>Congestion</strong>: The overflow of routing demand in each tile.</li><li><strong>DRC violations</strong>: The number of DRC violations in each tile.</li></ol></li><li><p><strong>IR Drop Features</strong>:</p><ol><li><strong>Instance power</strong>: The instance level internal, switching and leakage power along with the toggles rate from a vectorless power analysis.</li><li><strong>Signal arrival timing window</strong>: The possible switching time domain of the instance in a clock period from a static timing analysis for each pin.</li><li><strong>IR drop</strong>: The IR drop value on each node from a vectorless power rail analysis.</li></ol></li></ul><h2 id="graph-features" tabindex="-1"><a class="header-anchor" href="#graph-features"><span>Graph Features</span></a></h2><p>The connectivity of the design along with possible node and edge features are saved to enable prediction tasks on graph. See the <a href="https://circuitnet.github.io/feature/graph.html" target="_blank" rel="noopener noreferrer">graph feature page</a> for more detailed descriptions.</p><ul><li><p><strong>Graph Features from Netlist after Synthesis</strong>: Intended for GNN-based congestion prediction. We provide the pin to cell and pin to net mapping from the netlist to enable graph construction and the instance (cell) placement (in both micron and Gcell coordinate) as cell features.</p></li><li><p><strong>Graph Features from SDF (standard delay format)</strong>: Intended for GNN-based net delay prediction. We provide the pin-oriented graph from the SDF file and pin positions as node features.</p></li></ul><h2 id="supported-prediction-tasks" tabindex="-1"><a class="header-anchor"
